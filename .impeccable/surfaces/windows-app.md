# Windows application

Mode: Operate. Documentation is a Read surface inside the same shell.

Selection: the human pinned the replacement world in the request (Apple-like
liquid glass, no colored glows) and confirmed "white for light + dark grey".
This native code-led direction did not use a catalog roll, quality-bar card or
approved comp. Per new-work's pinned-direction route, mode-operate.md supplied
the task/control constraints. Apple HIG Materials and the rdev/liquid-glass-react
reference set the material/legibility bar; they do not change the WPF stack.

## Direction contract

**Thesis.** A neutral calibration utility: clear controls over white or graphite,
with restrained translucent navigation. The user explicitly replaces the former
purple/blue cockpit styling.

**Own-world.** White light theme and dark-gray dark theme, Segoe UI, charcoal
text, thin neutral edges, soft offset depth. Generated monitor/LUT identity and
matching navigation icons. Color is reserved for meaningful status and the LUT icon.

**First viewport.** Literal page title; compact settings rows with a left label,
right control and a short explanation beneath. Dithering uses one selector row.
Shortcut values are text, alongside consistent Edit and Remove actions.

**Story.** Assign per-display LUTs on Displays, enable correction, adjust optional
SDR dithering in Settings, and open the relevant Documentation topic for deeper
behavior or a playback workaround. Library and About retain their practical jobs.

**Form.** Native left navigation and WPF controls, a compact setting grid and
560-DIP reading column. White/graphite surfaces use neutral edges and a restrained
translucent navigation layer; readability and accurate state outrank refraction.

**Signature interaction.** Selecting a mode updates its explanation immediately.
Documentation has topic navigation and expandable technical explanations.

**Motion.** Fast control feedback, at most 160 ms for occasional disclosures;
keyboard navigation stays immediate. Respect Windows' animation preference.

**Quality boundary.** Review actual WPF captures in white and dark gray at normal
and minimum width. Check copy, localization coverage, shortcut save/remove and
registration behavior. No web detector can certify XAML or DWM playback.
